# OSTRZEŻENIE merytoryczne dot. apiScopes = ["User.Read"]
# =============================================================================
# "User.Read" to scope Microsoft Graph. Token wydany pod ten scope ma
#   aud = https://graph.microsoft.com (a nie Twoje API).
# Jeśli backend (D2ApiViewerEditor) waliduje audience swojego API
#   (AzureAd:ClientId / api://<API_CLIENT_ID>), taki token zostanie ODRZUCONY => 401,
#   mimo że logowanie się powiedzie i token będzie w localStorage.
#
# Do wołania WŁASNEGO backendu użyj scope'a swojego API, np.:
#   apiScopes:
#     - api://<API_CLIENT_ID>/access_as_user
#
# "User.Read" zostaw tylko jeśli faktycznie wołasz Grapha (np. profil/zdjęcie),
# a backend nie sprawdza audience swojego API.
